🔍 Task Overview:
You are tasked with creating a simple, interactive sales dashboard using Power BI or Tableau. The goal is to visualize and analyze sales performance based on different dimensions like product category, region, and time (months). This exercise is designed to help you understand data visualization, dashboard design, and insight generation, which are essential skills for a data analyst.

🧰 Tools Required:
Power BI (Recommended for beginners due to its drag-and-drop interface and strong integration with Microsoft tools)
OR
Tableau (Great for advanced visuals and interactivity)
(Optional): Python (Pandas) – If your dataset is messy, you can clean or preprocess it using Python before importing it.

📊 Dataset Description:
You’ll be using a sales dataset (such as Superstore_Sales.csv) with the following key columns:
Order Date: The date of each sale
Region: The geographic area where the sale occurred (e.g., West, East)
Category: Type of product sold (e.g., Furniture, Office Supplies, Technology)
Sales: Revenue generated from each order
Profit: Profit earned from each order

📈 Dashboard Design Instructions (Step-by-Step):
Step 1: Import Data
Open Power BI or Tableau.
Load the Superstore_Sales.csv file into your tool.
Make sure all columns are recognized correctly (especially date and numerical fields).

Step 2: Date Formatting
Convert the Order Date field to a “Month-Year” format (e.g., Jan-2023).
In Power BI, use the Date hierarchy or create a new column using FORMAT([Order Date], "MMM-YYYY").

Step 3: Add Visuals
Create 3 visuals that show different perspectives of sales performance:
Line Chart – Sales Over Months
X-axis: Month-Year
Y-axis: Total Sales
Shows trends over time and seasonal variations.
Bar Chart – Sales by Region
X-axis: Regions
Y-axis: Sales
Helps identify which region is performing better.
Donut Chart – Sales by Category
Each slice represents a product category.
Helps to visualize contribution of each product category to total sales.

Step 4: Add Filters/Slicers
Add an interactive slicer or dropdown filter for either Region or Category.
This allows users to explore sales patterns by specific areas or products.
For example, when selecting "East", the whole dashboard should adjust to show East's data.

Step 5: Use Colors Effectively
Use color coding to highlight top-performing regions or categories.
For example, green for high sales/profit, red for low.
This improves the readability and impact of the dashboard.

✍️ Deliverables:
1. Screenshot or PDF Export
Export your final dashboard as a PDF or take a screenshot to show your design.
Make sure all visuals are clean, properly labeled, and easy to interpret.

2. 3–4 Insights (Text File or Slide)
Write 3 to 4 short data insights based on your dashboard.
Examples:
“The West region consistently outperforms others in monthly sales.”
“Technology category had the highest contribution to total sales in Q2.”
“Sales dipped in February across all regions, indicating seasonality.”

You can put these insights in:
A Word/Text file
A PowerPoint slide

✅ What You Will Learn:
By completing this task, you’ll learn:
How to import and clean data
How to use visual elements to represent sales data
How to add interactivity with filters/slicers
How to summarize data and extract useful insights

This is a practical and essential exercise for anyone aiming to become a Data Analyst, as it simulates a real-world business reporting scenario.
